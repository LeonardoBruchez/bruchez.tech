# Bruchez 3D

Site premium em React + TypeScript para apresentar meu trabalho em impressão 3D, com foco em portfólio, prova social e conversão para WhatsApp.

## Como rodar

```bash
npm install
npm run dev
```

## Conteúdo que você pode trocar depois

- Inserir meus vídeos reais na seção de vídeo.
- Trocar os links reais de Instagram e Facebook.
- Adicionar minhas fotos reais das peças nas áreas de portfólio.
